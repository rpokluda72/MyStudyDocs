1. Introduction

Sequelize is the oldest and most widely adopted ORM for Node.js, first released in 2011. It follows an Active Record pattern where model instances map directly to database rows and carry methods for persistence. Sequelize supports MySQL, PostgreSQL, SQLite, and MSSQL through a unified Promise-based API.

Key Concepts

  • Model — JavaScript class that maps to a table; defined with sequelize.define() or Model.init().
  • Instance — a single row returned as a Model instance with save(), destroy(), reload().
  • QueryInterface — low-level DDL API used by migrations.
  • Associations — hasOne, hasMany, belongsTo, belongsToMany define inter-model relationships.
  • Op — Symbol-keyed operators (Op.gt, Op.like, Op.and) for WHERE clauses.

When to Use

  • Large Node.js projects that need mature, battle-tested tooling with a wide community.
  • Teams migrating from Rails-style Active Record who want a familiar mental model.
  • Projects that need to support multiple database backends from a single codebase.

When NOT to Use

  • TypeScript-first projects requiring full end-to-end type safety (consider Prisma instead).
  • Projects with very complex queries where ORM abstraction adds friction.

2. Installation & Setup

Install Packages

# Core library + MySQL driver

npm install sequelize mysql2

# Optional: CLI for migrations and seeders

npm install --save-dev sequelize-cli

Database Connection

Create a single Sequelize instance that is reused across the application:

// db.ts

import { Sequelize } from 'sequelize';

export const sequelize = new Sequelize(

'blog_db',

'root',

'secret',

{

host: 'localhost',

dialect: 'mysql',

charset: 'utf8mb4',

logging: false,

pool: { max: 10, min: 0, acquire: 30000, idle: 10000 },

}

);

sequelize.authenticate()

.then(() => console.log('DB connected'))

.catch((err) => console.error('Connection error:', err));

sync() vs Migrations
sequelize.sync({ force: true }) re-creates tables on every restart — never use in production. Use sequelize-cli migrations for production schema management.

3. Schema Definition

Each model is defined with sequelize.define() or by extending Model. The Blog system uses five models: User, Post, Comment, Tag, and the PostTag junction.

User Model

// models/User.ts

import { DataTypes, Model, InferAttributes, InferCreationAttributes } from 'sequelize';

import { sequelize } from '../db';

export class User extends Model<

InferAttributes<User>,

InferCreationAttributes<User>

> {

declare id: number;

declare username: string;

declare email: string;

declare passwordHash: string;

declare createdAt: Date;

}

User.init({

id: { type: DataTypes.INTEGER.UNSIGNED, autoIncrement: true, primaryKey: true },

username: { type: DataTypes.STRING(50), allowNull: false, unique: true },

email: { type: DataTypes.STRING(255), allowNull: false, unique: true },

passwordHash: { type: DataTypes.STRING(255), allowNull: false },

createdAt: { type: DataTypes.DATE, defaultValue: DataTypes.NOW },

}, {

sequelize,

tableName: 'users',

timestamps: false,

});

Post Model

// models/Post.ts

import { DataTypes, Model } from 'sequelize';

import { sequelize } from '../db';

export class Post extends Model {

declare id: number;

declare title: string;

declare content: string;

declare status: 'draft' | 'published';

declare authorId: number;

declare createdAt: Date;

declare updatedAt: Date;

}

Post.init({

id: { type: DataTypes.INTEGER.UNSIGNED, autoIncrement: true, primaryKey: true },

title: { type: DataTypes.STRING(255), allowNull: false },

content: { type: DataTypes.TEXT, allowNull: false },

status: { type: DataTypes.ENUM('draft', 'published'), defaultValue: 'draft' },

authorId: { type: DataTypes.INTEGER.UNSIGNED, allowNull: false },

}, {

sequelize,

tableName: 'posts',

timestamps: true, // adds createdAt + updatedAt automatically

});

Tag Model & Associations

// models/Tag.ts + associations setup

import { DataTypes, Model } from 'sequelize';

import { sequelize } from '../db';

import { User } from './User';

import { Post } from './Post';

import { Comment } from './Comment';

export class Tag extends Model {

declare id: number;

declare name: string;

}

Tag.init({

id: { type: DataTypes.INTEGER.UNSIGNED, autoIncrement: true, primaryKey: true },

name: { type: DataTypes.STRING(100), allowNull: false, unique: true },

}, { sequelize, tableName: 'tags', timestamps: false });

// ── Define all associations (run after all models are initialised) ───

User.hasMany(Post, { foreignKey: 'authorId', as: 'posts' });

Post.belongsTo(User, { foreignKey: 'authorId', as: 'author' });

Post.hasMany(Comment, { foreignKey: 'postId', as: 'comments' });

Comment.belongsTo(Post, { foreignKey: 'postId', as: 'post' });

Comment.belongsTo(User, { foreignKey: 'authorId', as: 'author' });

Post.belongsToMany(Tag, { through: 'post_tags', foreignKey: 'postId', as: 'tags' });

Tag.belongsToMany(Post, { through: 'post_tags', foreignKey: 'tagId', as: 'posts' });

4. CRUD Operations

Create

const post = await Post.create({

title: 'Getting Started with Sequelize',

content: 'Sequelize is a Node.js ORM...',

status: 'draft',

authorId: 1,

});

console.log(post.id); // auto-incremented PK

Find by Primary Key

const post = await Post.findByPk(42);

if (!post) throw new Error('Post not found');

Find All

const posts = await Post.findAll({

where: { status: 'published' },

order: [['createdAt', 'DESC']],

});

Update

// Update a single instance

post.title = 'Updated Title';

await post.save();

// Bulk update — returns [affectedCount]

await Post.update(

{ status: 'published' },

{ where: { authorId: 1 } }

);

Delete

await post.destroy(); // instance

await Post.destroy({ where: { status: 'draft' } }); // bulk

5. Querying

WHERE with Multiple Conditions

import { Op } from 'sequelize';

const posts = await Post.findAll({

where: {

authorId: 5,

status: 'published',

},

order: [['createdAt', 'DESC']],

});

Pagination

const PAGE = 2;

const PER_PAGE = 10;

const { count, rows } = await Post.findAndCountAll({

where: { status: 'published' },

limit: PER_PAGE,

offset: (PAGE - 1) * PER_PAGE,

order: [['createdAt', 'DESC']],

});

console.log(`Page ${PAGE} of ${Math.ceil(count / PER_PAGE)}`);

Select Specific Fields

const posts = await Post.findAll({

attributes: ['title', 'createdAt'],

where: { status: 'published' },

});

LIKE Search

const posts = await Post.findAll({

where: { title: { [Op.like]: '%sequelize%' } },

});

6. Associations

Load Posts with Author (1:N)

const posts = await Post.findAll({

include: [{ model: User, as: 'author', attributes: ['username', 'email'] }],

where: { status: 'published' },

});

posts.forEach(p => console.log(p.title, p.author?.username));

Nested Create — Post with First Comment

const post = await Post.create({

title: 'New Post',

content: 'Content here...',

status: 'draft',

authorId: 1,

comments: [{ content: 'First comment!', authorId: 2 }],

}, {

include: [{ model: Comment, as: 'comments' }],

});

Many-to-Many — Post with Tags

const post = await Post.findByPk(1, {

include: [{ model: Tag, as: 'tags' }],

});

// Create or find a tag and attach it

const [tag] = await Tag.findOrCreate({ where: { name: 'nodejs' } });

await post.addTag(tag);

post.tags?.forEach(t => console.log(t.name));

7. Migrations

CLI Commands

# Initialise project (creates migrations/, seeders/, config/)

npx sequelize-cli init

# Generate a migration file

npx sequelize-cli migration:generate --name create-users

# Run all pending migrations

npx sequelize-cli db:migrate

# Undo the last migration

npx sequelize-cli db:migrate:undo

# Undo all migrations

npx sequelize-cli db:migrate:undo:all

Sample Migration File

// migrations/20240101000001-create-users.js

'use strict';

module.exports = {

async up(queryInterface, Sequelize) {

await queryInterface.createTable('users', {

id: {

type: Sequelize.INTEGER.UNSIGNED,

autoIncrement: true,

primaryKey: true,

},

username: { type: Sequelize.STRING(50), allowNull: false, unique: true },

email: { type: Sequelize.STRING(255), allowNull: false, unique: true },

passwordHash: { type: Sequelize.STRING(255), allowNull: false },

createdAt: { type: Sequelize.DATE, defaultValue: Sequelize.NOW },

});

},

async down(queryInterface) {

await queryInterface.dropTable('users');

},

};

8. Transactions

Use sequelize.transaction() with the managed form — the transaction is automatically committed or rolled back based on whether the callback throws:

const { post, comment } = await sequelize.transaction(async (t) => {

const post = await Post.create({

title: 'Atomic Post',

content: 'Created inside a transaction.',

status: 'draft',

authorId: 1,

}, { transaction: t });

const comment = await Comment.create({

content: 'First comment on the new post.',

postId: post.id,

authorId: 2,

}, { transaction: t });

return { post, comment };

});

// If any operation throws, both inserts are rolled back automatically.

Unmanaged (Manual) Transaction

const t = await sequelize.transaction();

try {

await Post.create(

{ title: 'Manual tx', content: '...', status: 'draft', authorId: 1 },

{ transaction: t }

);

await t.commit();

} catch (err) {

await t.rollback();

throw err;

}

9. Raw / Advanced Queries

Find the top 5 authors by number of published posts, returning username, email, and count:

Using sequelize.query() — Raw SQL

import { QueryTypes } from 'sequelize';

const results = await sequelize.query(

`SELECT u.id, u.username, u.email, COUNT(p.id) AS postCount

FROM users u

JOIN posts p ON p.authorId = u.id

WHERE p.status = 'published'

GROUP BY u.id

ORDER BY postCount DESC

LIMIT 5`,

{ type: QueryTypes.SELECT }

);

results.forEach(r => console.log(r.username, r.postCount));

Using Model.findAll with fn / col

import { fn, col, literal } from 'sequelize';

const results = await User.findAll({

attributes: [

'id', 'username', 'email',

[fn('COUNT', col('posts.id')), 'postCount'],

],

include: [{

model: Post,

as: 'posts',

attributes: [],

where: { status: 'published' },

required: true,

}],

group: ['User.id'],

order: [[literal('postCount'), 'DESC']],

limit: 5,

subQuery: false,

});
