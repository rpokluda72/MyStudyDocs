1. Introduction

TypeORM (2016) is a TypeScript-first ORM that uses ES6/ES7 decorator metadata to map classes to database tables. It supports both Active Record and Data Mapper patterns and integrates tightly with TypeScript's type system, making it the go-to ORM for NestJS projects.

Key Concepts

  • Entity — a class decorated with @Entity() that maps to a database table.
  • DataSource — the connection config object; the entry point to all DB operations (v0.3+).
  • Repository<T> — obtained via dataSource.getRepository(Entity); provides CRUD + query methods.
  • QueryBuilder — fluent API for building complex SQL with full TypeScript support.
  • Decorators — @Column, @PrimaryGeneratedColumn, @OneToMany, @ManyToMany, etc.

When to Use

  • TypeScript projects, especially NestJS apps, needing decorator-based DI and strong typing.
  • Teams who prefer writing domain classes that mirror the database schema.
  • Projects that need both Active Record convenience and Data Mapper testability.

When NOT to Use

  • JavaScript-only projects (Sequelize has much wider JS community support).
  • Projects where adding reflect-metadata and tsconfig decorator flags is not acceptable.

2. Installation & Setup

Install Packages

npm install typeorm mysql2 reflect-metadata

tsconfig.json

TypeORM requires experimental decorator support. Add these compiler options:

{

"compilerOptions": {

"target": "ES2020",

"module": "commonjs",

"experimentalDecorators": true,

"emitDecoratorMetadata": true,

"strict": true

}

}

Entry Point — import reflect-metadata first

reflect-metadata must be the very first import in your application entry file:

// index.ts

import 'reflect-metadata'; // MUST be first

import { AppDataSource } from './data-source';

AppDataSource.initialize()

.then(() => console.log('DB connected'))

.catch(console.error);

DataSource Configuration

// data-source.ts

import { DataSource } from 'typeorm';

import { User } from './entity/User';

import { Post } from './entity/Post';

import { Comment } from './entity/Comment';

import { Tag } from './entity/Tag';

export const AppDataSource = new DataSource({

type: 'mysql',

host: 'localhost',

port: 3306,

username: 'root',

password: 'secret',

database: 'blog_db',

charset: 'utf8mb4',

entities: [User, Post, Comment, Tag],

migrations: ['src/migration/*.ts'],

synchronize: false, // never true in production

logging: false,

});

3. Schema Definition

Each entity is a TypeScript class decorated with @Entity(). Relationships are declared directly on the entity using @OneToMany / @ManyToOne / @ManyToMany.

User Entity

// entity/User.ts

import { Entity, PrimaryGeneratedColumn, Column, CreateDateColumn, OneToMany } from 'typeorm';

import { Post } from './Post';

import { Comment } from './Comment';

@Entity('users')

export class User {

@PrimaryGeneratedColumn({ unsigned: true })

id: number;

@Column({ length: 50, unique: true })

username: string;

@Column({ length: 255, unique: true })

email: string;

@Column({ length: 255 })

passwordHash: string;

@CreateDateColumn()

createdAt: Date;

@OneToMany(() => Post, post => post.author)

posts: Post[];

@OneToMany(() => Comment, comment => comment.author)

comments: Comment[];

}

Post Entity

// entity/Post.ts

import {

Entity, PrimaryGeneratedColumn, Column, CreateDateColumn, UpdateDateColumn,

ManyToOne, OneToMany, ManyToMany, JoinTable,

} from 'typeorm';

import { User } from './User';

import { Comment } from './Comment';

import { Tag } from './Tag';

@Entity('posts')

export class Post {

@PrimaryGeneratedColumn({ unsigned: true })

id: number;

@Column({ length: 255 })

title: string;

@Column({ type: 'text' })

content: string;

@Column({ type: 'enum', enum: ['draft', 'published'], default: 'draft' })

status: 'draft' | 'published';

@ManyToOne(() => User, user => user.posts)

author: User;

@OneToMany(() => Comment, comment => comment.post)

comments: Comment[];

// TypeORM auto-creates the post_tags junction table from @JoinTable

@ManyToMany(() => Tag, tag => tag.posts)

@JoinTable({ name: 'post_tags' })

tags: Tag[];

@CreateDateColumn() createdAt: Date;

@UpdateDateColumn() updatedAt: Date;

}

Comment Entity

// entity/Comment.ts

import { Entity, PrimaryGeneratedColumn, Column, CreateDateColumn, ManyToOne } from 'typeorm';

import { Post } from './Post';

import { User } from './User';

@Entity('comments')

export class Comment {

@PrimaryGeneratedColumn({ unsigned: true })

id: number;

@Column({ type: 'text' })

content: string;

@ManyToOne(() => Post, post => post.comments)

post: Post;

@ManyToOne(() => User, user => user.comments)

author: User;

@CreateDateColumn()

createdAt: Date;

}

Tag Entity

// entity/Tag.ts

import { Entity, PrimaryGeneratedColumn, Column, ManyToMany } from 'typeorm';

import { Post } from './Post';

@Entity('tags')

export class Tag {

@PrimaryGeneratedColumn({ unsigned: true })

id: number;

@Column({ length: 100, unique: true })

name: string;

@ManyToMany(() => Post, post => post.tags)

posts: Post[];

}

4. CRUD Operations

Get a typed repository via AppDataSource.getRepository(Entity):

const postRepo = AppDataSource.getRepository(Post);

Create

const post = postRepo.create({

title: 'Getting Started with TypeORM',

content: 'TypeORM uses TypeScript decorators...',

status: 'draft',

author: { id: 1 }, // reference by ID — no need to load the full User

});

await postRepo.save(post);

console.log(post.id); // populated after save()

Find by Primary Key

const post = await postRepo.findOneBy({ id: 42 });

if (!post) throw new Error('Post not found');

Find All

const posts = await postRepo.find({

where: { status: 'published' },

order: { createdAt: 'DESC' },

});

Update

// Update via save()

post.title = 'Updated Title';

await postRepo.save(post);

// Partial update — no need to load the entity first

await postRepo.update({ author: { id: 1 } }, { status: 'published' });

Delete

await postRepo.delete(42); // by PK

await postRepo.delete({ status: 'draft' }); // by criteria

5. Querying

WHERE with Multiple Conditions

const posts = await postRepo.find({

where: {

author: { id: 5 },

status: 'published',

},

order: { createdAt: 'DESC' },

});

Pagination

const PAGE = 2;

const PER_PAGE = 10;

const [posts, total] = await postRepo.findAndCount({

where: { status: 'published' },

order: { createdAt: 'DESC' },

take: PER_PAGE,

skip: (PAGE - 1) * PER_PAGE,

});

console.log(`Page ${PAGE} of ${Math.ceil(total / PER_PAGE)}`);

Select Specific Fields

const posts = await postRepo.find({

select: { title: true, createdAt: true },

where: { status: 'published' },

});

LIKE Search with QueryBuilder

const posts = await postRepo

.createQueryBuilder('post')

.where('post.title LIKE :kw', { kw: '%typeorm%' })

.orderBy('post.createdAt', 'DESC')

.getMany();

6. Associations

Load Posts with Author (1:N)

const posts = await postRepo.find({

relations: { author: true },

where: { status: 'published' },

});

posts.forEach(p => console.log(p.title, p.author.username));

Nested Create — Post with First Comment

const post = postRepo.create({

title: 'New Post',

content: 'Content here...',

status: 'draft',

author: { id: 1 },

comments: [{ content: 'First comment!', author: { id: 2 } }],

});

await postRepo.save(post);

Many-to-Many — Post with Tags

const post = await postRepo.findOne({

where: { id: 1 },

relations: { tags: true },

});

post?.tags.forEach(t => console.log(t.name));

7. Migrations

CLI Commands

# Generate migration from entity changes

npx typeorm migration:generate src/migration/CreateBlogTables -d src/data-source.ts

# Run all pending migrations

npx typeorm migration:run -d src/data-source.ts

# Revert the last migration

npx typeorm migration:revert -d src/data-source.ts

# Show migration status

npx typeorm migration:show -d src/data-source.ts

Sample Migration File

// src/migration/1704067200000-CreateUsers.ts

import { MigrationInterface, QueryRunner, Table } from 'typeorm';

export class CreateUsers1704067200000 implements MigrationInterface {

async up(queryRunner: QueryRunner): Promise<void> {

await queryRunner.createTable(new Table({

name: 'users',

columns: [

{ name: 'id', type: 'int unsigned', isPrimary: true, isGenerated: true },

{ name: 'username', type: 'varchar(50)', isUnique: true, isNullable: false },

{ name: 'email', type: 'varchar(255)', isUnique: true, isNullable: false },

{ name: 'passwordHash', type: 'varchar(255)', isNullable: false },

{ name: 'createdAt', type: 'datetime', default: 'CURRENT_TIMESTAMP' },

],

}));

}

async down(queryRunner: QueryRunner): Promise<void> {

await queryRunner.dropTable('users');

}

}

8. Transactions

TypeORM offers two transaction patterns. The QueryRunner approach (try/catch/finally) is the most explicit; the shorthand dataSource.transaction() is more concise:

QueryRunner Pattern

const qr = AppDataSource.createQueryRunner();

await qr.connect();

await qr.startTransaction();

try {

const post = qr.manager.create(Post, {

title: 'Atomic Post',

content: 'Inside a transaction.',

status: 'draft',

author: { id: 1 },

});

await qr.manager.save(post);

const comment = qr.manager.create(Comment, {

content: 'First comment.',

post: { id: post.id },

author: { id: 2 },

});

await qr.manager.save(comment);

await qr.commitTransaction();

} catch (err) {

await qr.rollbackTransaction();

throw err;

} finally {

await qr.release();

}

Shorthand — dataSource.transaction()

await AppDataSource.transaction(async (manager) => {

const post = manager.create(Post, {

title: 'Tx Post', content: '...', status: 'draft', author: { id: 1 },

});

await manager.save(post);

await manager.save(Comment, {

content: 'Comment.', post: { id: post.id }, author: { id: 2 },

});

});

9. Raw / Advanced Queries

Top 5 authors by published post count:

QueryBuilder with GROUP BY

const results = await AppDataSource

.createQueryBuilder(User, 'user')

.innerJoin('user.posts', 'post', 'post.status = :s', { s: 'published' })

.select(['user.id', 'user.username', 'user.email'])

.addSelect('COUNT(post.id)', 'postCount')

.groupBy('user.id')

.orderBy('postCount', 'DESC')

.limit(5)

.getRawMany<{ user_id: number; user_username: string; postCount: string }>();

results.forEach(r => console.log(r.user_username, r.postCount));

Raw SQL via QueryRunner

const qr = AppDataSource.createQueryRunner();

await qr.connect();

const rows = await qr.query(

`SELECT u.username, COUNT(p.id) AS postCount

FROM users u

JOIN posts p ON p.authorId = u.id AND p.status = 'published'

GROUP BY u.id ORDER BY postCount DESC LIMIT 5`

);

await qr.release();
