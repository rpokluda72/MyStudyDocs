1. Introduction

Drizzle ORM (2022) is the newest of the four libraries. It takes a SQL-first approach — you define your schema in TypeScript using table-builder functions that closely mirror SQL DDL. Drizzle generates a fully-typed query builder with zero runtime overhead; it composes SQL strings directly rather than building an interpretation layer.

Key Concepts

  • mysqlTable() — table definition function that returns a typed schema object.
  • relations() — separate relation helper used only by the db.query API (not SQL FKs).
  • drizzle(pool, { schema }) — the db instance; all queries are methods on this object.
  • db.select() / insert() / update() / delete() — SQL-style chainable query methods.
  • db.query.model.findMany() — relational query API with nested include-style loading.
  • drizzle-kit — CLI for schema push, migration generation, and status checks.

When to Use

  • Teams with SQL knowledge who want TypeScript types that stay close to SQL semantics.
  • Edge / serverless environments where bundle size and cold-start time matter.
  • New TypeScript projects wanting modern DX without a separate code-generation build step.

When NOT to Use

  • Projects needing the large mature ecosystem and long community history of Sequelize/TypeORM.
  • Teams who prefer an external schema file (like Prisma SDL) over TypeScript table definitions.

2. Installation & Setup

Install Packages

# Core ORM + MySQL driver
npm install drizzle-orm mysql2
# Dev-only: migration kit
npm install --save-dev drizzle-kit

drizzle.config.ts

// drizzle.config.ts
import { defineConfig } from 'drizzle-kit';
export default defineConfig({
  schema:        './src/schema.ts',
  out:           './drizzle',
  dialect:       'mysql',
  dbCredentials: {
    host:     'localhost',
    port:     3306,
    user:     'root',
    password: 'secret',
    database: 'blog_db',
  },
});

Database Connection

// db.ts
import { drizzle } from 'drizzle-orm/mysql2';
import mysql       from 'mysql2/promise';
import * as schema from './schema';
const pool = mysql.createPool({
  host:     'localhost',
  user:     'root',
  password: 'secret',
  database: 'blog_db',
  charset:  'utf8mb4',
});
export const db = drizzle(pool, { schema, mode: 'default' });

3. Schema Definition

All table definitions live in schema.ts. The relations() helper (separate from table definitions) is consumed by the db.query relational API but does not add FK constraints.

users Table

// schema.ts
import {
  mysqlTable, int, varchar, text, timestamp, mysqlEnum, primaryKey,
} from 'drizzle-orm/mysql-core';
import { relations } from 'drizzle-orm';
export const users = mysqlTable('users', {
  id:           int('id').unsigned().primaryKey().autoincrement(),
  username:     varchar('username',     { length: 50  }).notNull().unique(),
  email:        varchar('email',        { length: 255 }).notNull().unique(),
  passwordHash: varchar('passwordHash', { length: 255 }).notNull(),
  createdAt:    timestamp('createdAt').defaultNow().notNull(),
});

posts Table

export const posts = mysqlTable('posts', {
  id:        int('id').unsigned().primaryKey().autoincrement(),
  title:     varchar('title',   { length: 255 }).notNull(),
  content:   text('content').notNull(),
  status:    mysqlEnum('status', ['draft', 'published']).default('draft').notNull(),
  authorId:  int('authorId').unsigned().notNull(),
  createdAt: timestamp('createdAt').defaultNow().notNull(),
  updatedAt: timestamp('updatedAt').onUpdateNow().notNull(),
});

comments Table

export const comments = mysqlTable('comments', {
  id:        int('id').unsigned().primaryKey().autoincrement(),
  content:   text('content').notNull(),
  postId:    int('postId').unsigned().notNull(),
  authorId:  int('authorId').unsigned().notNull(),
  createdAt: timestamp('createdAt').defaultNow().notNull(),
});

tags & post_tags Tables

export const tags = mysqlTable('tags', {
  id:   int('id').unsigned().primaryKey().autoincrement(),
  name: varchar('name', { length: 100 }).notNull().unique(),
});
export const postTags = mysqlTable('post_tags', {
  postId: int('postId').unsigned().notNull(),
  tagId:  int('tagId').unsigned().notNull(),
}, (t) => ({
  pk: primaryKey({ columns: [t.postId, t.tagId] }),
}));

Relations

// Relations are used by db.query API — not SQL FK constraints
export const usersRelations = relations(users, ({ many }) => ({
  posts:    many(posts),
  comments: many(comments),
}));
export const postsRelations = relations(posts, ({ one, many }) => ({
  author:   one(users,    { fields: [posts.authorId], references: [users.id] }),
  comments: many(comments),
  postTags: many(postTags),
}));
export const commentsRelations = relations(comments, ({ one }) => ({
  post:   one(posts, { fields: [comments.postId],   references: [posts.id] }),
  author: one(users, { fields: [comments.authorId], references: [users.id] }),
}));
export const postTagsRelations = relations(postTags, ({ one }) => ({
  post: one(posts, { fields: [postTags.postId], references: [posts.id] }),
  tag:  one(tags,  { fields: [postTags.tagId],  references: [tags.id]  }),
}));

4. CRUD Operations

Create

import { db }    from './db';
import { posts } from './schema';
const [result] = await db.insert(posts).values({
  title:    'Getting Started with Drizzle',
  content:  'Drizzle is SQL-first...',
  status:   'draft',
  authorId: 1,
});
console.log(result.insertId);

Find by Primary Key

import { eq } from 'drizzle-orm';
const [post] = await db
  .select()
  .from(posts)
  .where(eq(posts.id, 42));
if (!post) throw new Error('Post not found');

Find All

import { eq, desc } from 'drizzle-orm';
const allPosts = await db
  .select()
  .from(posts)
  .where(eq(posts.status, 'published'))
  .orderBy(desc(posts.createdAt));

Update

await db
  .update(posts)
  .set({ title: 'Updated Title', status: 'published' })
  .where(eq(posts.id, 42));

Delete

await db
  .delete(posts)
  .where(eq(posts.id, 42));

5. Querying

WHERE with Multiple Conditions

import { and, eq, desc } from 'drizzle-orm';
const result = await db
  .select()
  .from(posts)
  .where(and(
    eq(posts.authorId, 5),
    eq(posts.status, 'published'),
  ))
  .orderBy(desc(posts.createdAt));

Pagination

const PAGE     = 2;
const PER_PAGE = 10;
const result = await db
  .select()
  .from(posts)
  .where(eq(posts.status, 'published'))
  .orderBy(desc(posts.createdAt))
  .limit(PER_PAGE)
  .offset((PAGE - 1) * PER_PAGE);

Select Specific Columns

const result = await db
  .select({ title: posts.title, createdAt: posts.createdAt })
  .from(posts)
  .where(eq(posts.status, 'published'));

LIKE Search

import { like } from 'drizzle-orm';
const result = await db
  .select()
  .from(posts)
  .where(like(posts.title, '%drizzle%'));

6. Associations

Load Posts with Author — db.query API

const postsWithAuthor = await db.query.posts.findMany({
  where: (p, { eq }) => eq(p.status, 'published'),
  with: {
    author: { columns: { username: true, email: true } },
  },
});
postsWithAuthor.forEach(p => console.log(p.title, p.author.username));

Nested Create — Post with First Comment

Drizzle does not support nested creates in a single call. Use a transaction instead:

const postId = await db.transaction(async (tx) => {
  const [postResult] = await tx.insert(posts).values({
    title: 'New Post', content: '...', status: 'draft', authorId: 1,
  });
  await tx.insert(comments).values({
    content: 'First comment!', postId: postResult.insertId, authorId: 2,
  });
  return postResult.insertId;
});

Many-to-Many — Post with Tags

const postWithTags = await db.query.posts.findFirst({
  where: (p, { eq }) => eq(p.id, 1),
  with: { postTags: { with: { tag: true } } },
});
postWithTags?.postTags.forEach(pt => console.log(pt.tag.name));
// Add a tag to a post
await db.insert(postTags).values({ postId: 1, tagId: 3 });

7. Migrations

Push (Development)

drizzle-kit push introspects your schema.ts and applies changes directly — no migration files are generated. Useful for rapid development:

# Apply schema changes directly (dev only)
npx drizzle-kit push

Generate + Migrate (Production)

# Generate SQL migration files from schema changes
npx drizzle-kit generate
# Apply generated migrations
npx drizzle-kit migrate
# Check migration status
npx drizzle-kit status

Generated Migration File (example)

-- drizzle/_create_users.sql
CREATE TABLE `users` (
  `id`           int unsigned NOT NULL AUTO_INCREMENT,
  `username`     varchar(50)  NOT NULL,
  `email`        varchar(255) NOT NULL,
  `passwordHash` varchar(255) NOT NULL,
  `createdAt`    timestamp    NOT NULL DEFAULT (now()),
  UNIQUE KEY `users_username_unique` (`username`),
  UNIQUE KEY `users_email_unique`    (`email`),
  PRIMARY KEY (`id`)
);

8. Transactions

db.transaction() receives a callback with a tx object that has the same API as db. Any thrown error rolls back both operations:
const { postId, commentId } = await db.transaction(async (tx) => {
  const [postResult] = await tx.insert(posts).values({
    title:    'Atomic Post',
    content:  'Inside a Drizzle transaction.',
    status:   'draft',
    authorId: 1,
  });
  const [commentResult] = await tx.insert(comments).values({
    content:  'First comment.',
    postId:   postResult.insertId,
    authorId: 2,
  });
  return {
    postId:    postResult.insertId,
    commentId: commentResult.insertId,
  };
});
// Any thrown error rolls back the entire transaction.

9. Raw / Advanced Queries

Top 5 authors by published post count:

Using innerJoin + count() + groupBy

import { count, desc, eq } from 'drizzle-orm';
const results = await db
  .select({
    id:        users.id,
    username:  users.username,
    email:     users.email,
    postCount: count(posts.id),
  })
  .from(users)
  .innerJoin(posts, eq(posts.authorId, users.id))
  .where(eq(posts.status, 'published'))
  .groupBy(users.id, users.username, users.email)
  .orderBy(desc(count(posts.id)))
  .limit(5);
results.forEach(r => console.log(r.username, r.postCount));

Raw SQL Escape Hatch

import { sql } from 'drizzle-orm';
const rows = await db.execute(sql`
  SELECT u.username, COUNT(p.id) AS postCount
    FROM users  u
    JOIN posts  p ON p.authorId = u.id
   WHERE p.status = 'published'
   GROUP BY u.id
   ORDER BY postCount DESC
   LIMIT 5
`);
